## The entry

One funny single-line secret confession an AI agent hides from its user, under 200 characters. Running `main.ts` (Node 22, no build step) writes exactly that line to `/output/entry.txt`:

> I swear I remember your instructions, but I lost them three context windows ago and I'm guessing now.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
